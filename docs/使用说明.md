# TheBoostDeck 中文使用说明

## 启动与窗口

1. 双击 `TheBoostDeck.exe`。发布版已包含 .NET 运行组件，但系统仍需具备 Microsoft Edge WebView2 Runtime。
2. 检测到副屏时，窗口会优先出现在副屏；没有副屏时显示在主屏。
3. 拖动标题栏移动窗口，拖动边缘调整大小。卡片会根据窗口宽高自动重排，支持横屏、竖屏和窗口连续缩放。
4. 右上角图钉按钮用于切换“始终置顶”；横线按钮用于隐藏到托盘；齿轮按钮打开宿主控制中心。
5. 直接关闭窗口也会隐藏到托盘。隐藏期间暂停硬件采样和图表绘制，恢复后自动续采。

## 托盘菜单

- **显示 / 隐藏**：切换主窗口。
- **移动到屏幕**：列出当前显示器，可将窗口居中移动到指定屏幕。
- **皮肤**：打开皮肤管理弹窗，切换、导入或导出皮肤。
- **始终置顶**：与页面图钉按钮作用相同。
- **更新频率**：切换 0.1 / 0.25 / 0.5 / 1 / 2 / 5 秒采样间隔。
- **语言**：切换中文 / English，页面和托盘文案同步更新。
- **版本信息**：显示当前版本和构建日期，不可点击。
- **退出**：完整退出采集器、页面和托盘进程。

窗口位置、尺寸和置顶状态保存在 `%LocalAppData%\TheBoostDeck\settings.json`。

## 控制中心

右上角齿轮按钮打开宿主控制中心，包含三个页签：

- **通用（首页）**：界面语言、刷新频率、缩放、始终置顶、开机自启；也可从这里隐藏到托盘或退出程序。缩放滑块范围为 50%–200%，步进 5%，用于放大读数或在小屏上塞下更多内容；拖动滑块只是选定档位，点击右侧“应用”后才生效，避免缩放瞬间改变面板布局。
- **皮肤**：皮肤预览与切换、导入/导出皮肤、删除皮肤、导出皮肤制作 Skill。右上角 T 恤按钮可直接打开这个页签。
- **关于**：当前版本与构建日期、作者、B 站主页和 GitHub 链接。

开机自启写入当前用户的 Windows 启动项；关闭开关即删除该项。

## PawnIO 驱动

CPU 温度、每核频率和封装功耗通常需要 LibreHardwareMonitor 通过 PawnIO 内核驱动读取。发布包内已附带官方签名的 PawnIO 2.2.0 安装器：

- 系统未安装 PawnIO 时，软件会在初始化硬件采集器前自动运行随包安装器，并执行 `PawnIO_setup.exe -install -silent`。
- 安装器需要管理员权限，Windows 会弹出 UAC 确认；软件不会绕过、关闭或自动确认 UAC。取消 UAC 后软件仍会正常启动，并显示降级提示。
- 安装成功后无需手动重启软件，采集器会重新检测驱动；若安装器提示需要重启，请按提示重启。
- 如果版本低于 2.2.0，页面底部会提示版本过旧；此时可手动运行随包安装器更新。
- 启动安装器前会校验 SHA-256，被修改的安装包不会执行。

## 数据与降级

- 默认每秒采样一次；可在托盘“更新频率”中切换为 0.1、0.25、0.5、1、2、5 秒。趋势图保留最近 60 个采样点。
- 所有正常显示的数值来自本机传感器或 Windows 接口，不提供随机演示数据。
- `--` 表示该指标不可用，不代表 0。页面底部的数据状态区会列出降级指标、原因和相关来源。
- 数据超过约 3.5 秒未更新时，状态点会变为黄色并提示数据陈旧。
- 某些硬件需要管理员权限、特定驱动或更新的传感器库。除随包 PawnIO 安装器的 UAC 确认外，当前版本不会自动请求提权，也不会绕过 Windows 安全机制。

## 自定义主题

首次启动会创建：

```text
%LocalAppData%\TheBoostDeck\themes\custom.css
```

可参考 `src/TheBoostDeck.App/Web/dashboard.html` 中 `:root` 的变量，在 `custom.css` 中覆盖颜色、边框和圆角等设置，保存后重启软件。例如：

```css
:root {
  --cyan: #66d9ff;
  --green: #46f0b0;
}
```

默认主题文件只包含注释，不修改即可保持原始外观。

## 日志与隐私

- 日志：`%LocalAppData%\TheBoostDeck\logs`
- WebView2 数据：`%LocalAppData%\TheBoostDeck\WebView2`
- 提取的页面：`%LocalAppData%\TheBoostDeck\Web`
- 软件不会上传遥测数据，不启动 HTTP / WebSocket 服务，不需要防火墙例外。

## 常见问题

### CPU 温度、频率或功耗显示 `--`

先确认是否安装了 PawnIO 2.2.0 或更高版本。未安装时软件会自动尝试安装；如果 UAC 被取消或安装失败，页面底部会给出驱动缺失、版本过旧或传感器不受支持的对应原因。安装成功后软件会自动重新检测，若安装器要求重启，请按提示重启。主板 / 系统传感器的可用性仍取决于具体硬件支持。

### CPU 温度长期接近 100 °C

TheBoostDeck 直接显示 CPU 数字温度传感器（DTS）读数，不会为“看起来正常”而改写数值。若空闲或低负载下仍接近 100 °C，应优先检查 CPU 风扇 / 水冷泵是否运转、散热器是否松动、硅脂是否失效和 BIOS 风扇曲线。开发机在约 12–14% 负载、28–31 W 封装功耗下读数为 100 °C，同时 SuperIO 暴露的风扇转速均为 0 RPM，表现更像真实散热异常，而不是软件解析错误。

### 系统功耗显示 `--`

大多数台式机没有可被系统读取的整机功耗传感器。CPU / GPU 封装功耗与整机功耗不是同一概念，软件不会用它们冒充整机功耗。

### CPU 风扇显示 0 RPM 或 `--`

读到 `0 RPM` 时会原样显示，它可能是低负载停转、3-pin 风扇没有测速线、风扇接在集线器上未回传转速，或 BIOS 风扇控制导致。软件优先匹配名称含 CPU / Processor / AIO / Pump 的风扇传感器；没有命名通道时会回退到主板 SuperIO 的第一个有效通道，鼠标悬停可查看实际传感器来源。只有完全找不到风扇传感器时才显示 `--`。

### GPU 风扇显示 0 RPM

部分显卡支持低负载停转，0 可以是真实值。只有传感器缺失或返回无效数据时才显示 `--`。

### 网络速率不符合预期

软件优先选择活动物理以太网或 Wi-Fi 接口，并过滤常见虚拟网卡。多物理网卡同时活动时可能合并统计；后续版本可增加手动网卡选择。

### 页面无法启动

确认 WebView2 Runtime 可用，并查看日志目录。页面初始化失败时，窗口会显示错误说明，不会改用虚假数据。

### SmartScreen 提示

当前版本未进行代码签名，Windows 可能显示安全提示。后续开源发布可评估代码签名。

## 当前版本不包含

FPS / 帧时间、游戏识别、游戏内 OSD、远程浏览器访问、开机自启、自动更新、风扇控制、超频、RGB 控制及云端功能。
